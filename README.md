# funny-crash-page
一个有趣又有创意的错误/崩溃页面项目 🎉

## ✨ 项目简介
这是一个趣味风格的错误页面（比如 404、程序崩溃页），用轻松幽默的方式替代了传统生硬的提示页，适合个人项目、小工具或网站使用，给用户带来一点小惊喜。

## 🚀 快速预览
> 等你开启 GitHub Pages 后，这里可以放上在线预览链接。

## 📦 使用方法
1.  直接下载项目里的 HTML/CSS/JS 文件
2.  放到你的项目中，按需求修改文案、配色和动效
3.  部署到服务器或 GitHub Pages 上即可访问

## 🎨 自定义修改
- 文案：修改 HTML 里的文字内容，换成你想要的提示语
- 样式：调整 CSS 文件里的颜色、字体和动画效果
- 功能：可以添加动态效果、彩蛋或跳转链接
